# oncology-surgery-guide

Clinical decision support tool that crosses ICD-10 oncology codes (C00–C96, D37–D48) with SIGTAP surgical procedures (subgroup 0304). Provides TNM staging, precision medicine and biomarker information, therapeutic schemes based on PCDT/NCCN/ESMO/ASCO, and compatibility auditing. Exports reports as PDF or Excel.

**Stack:** React 19, TypeScript, TanStack Start, Tailwind CSS 4, jsPDF, XLSX, Bun
